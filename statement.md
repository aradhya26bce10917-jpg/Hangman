# Project Statement

## Project Title

Hangman Game

## Problem Statement

Word guessing games can be used as a simple and interactive way to practice vocabulary, logical thinking, and programming concepts. However, a basic implementation can become difficult to manage when all the game logic is written in a single file.

This project develops a modular Python-based Hangman game in which the player guesses a randomly selected word one letter at a time while having a limited number of lives.

The project focuses on applying Python programming concepts through a structured and maintainable game.

## Project Scope

The project includes:

- Random word selection from a predefined word list.
- Letter-by-letter word guessing.
- Tracking of player lives and score.
- Display of guessed and unguessed letters.
- Hangman stage display.
- Input validation.
- Win and loss conditions.
- Modular organization using multiple Python files.
- Use of a Python class to manage player information.

The current version is a console-based application and does not include a graphical user interface or online multiplayer functionality.

## Target Users

The project is intended for:

- Students learning Python programming.
- Beginners interested in understanding modular programming.
- Users who enjoy simple word-guessing games.

## High-Level Features

1. **Random Word Selection**  
   A word is randomly selected from the predefined word list.

2. **Guess Processing**  
   The player enters one letter at a time and the program checks whether it occurs in the selected word.

3. **Lives and Score Management**  
   The player starts with six lives, while correct guesses contribute to the score.

4. **Progress Display**  
   Correctly guessed letters are revealed while unknown letters remain hidden.

5. **Hangman Display**  
   Different Hangman stages are displayed according to the player's remaining lives.

6. **Input Validation**  
   The program checks for invalid inputs and repeated guesses.

7. **Game Completion**  
   The game ends when the player successfully guesses the word or runs out of lives.
